# CV web · Javier Triguero Pomares

Web-currículum hecha con **React + Vite + Tailwind CSS**.

## Uso

```bash
npm install
npm run dev      # desarrollo en http://localhost:5173
npm run build    # genera la versión estática en dist/
```

## Editar contenido

Todo el texto del CV está en [`src/data/cv.js`](src/data/cv.js).
Para mostrar tu foto, guárdala como `public/foto.jpg` (si no existe se muestran las iniciales).
